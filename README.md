# 🛍️ LUMI – Moda Feminina

## 📌 Sobre o projeto
A LUMI é um projeto acadêmico de loja virtual de roupas femininas, desenvolvido para praticar conhecimentos de Front-end.

## 🎯 Objetivo
Criar uma interface de loja virtual organizada, intuitiva e visualmente agradável.

## 👩‍💻 Minha contribuição
Desenvolvimento das páginas HTML, estilização com CSS e organização dos arquivos do projeto.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- Git e GitHub
- Visual Studio Code

## 🚀 Como executar
1. Baixe ou clone o repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo login.html no navegador.
